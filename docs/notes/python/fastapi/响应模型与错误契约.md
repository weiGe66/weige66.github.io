接口处理函数拿到的对象可能比客户端需要的字段多。比如图书记录同时包含书名和内部备注，详情接口只需要公开 ID 和书名。错误也需要单独约定，客户端应能根据稳定的错误码处理，而文案可以独立调整。

## 把 HTTP 状态、响应结构和文档一起定下来

| 请求结果 | 状态码 | 响应契约 |
| --- | --- | --- |
| 找到图书 | 200 | 返回 `BookOut` 定义的字段 |
| 合法 ID 对应的图书不存在 | 404 | `detail` 包含稳定的 `code` 和用户可读的 `message` |
| ID 不满足路径参数约束 | 422 | FastAPI 返回请求校验问题 |

`response_model` 用于成功响应的序列化、校验和字段过滤，同时生成 OpenAPI Schema。额外的 `responses` 声明用来记录错误响应的结构。实际的 404 由 `HTTPException` 触发，它的 `detail` 会成为响应中的 `detail` 字段。 [FastAPI · Response Model](https://fastapi.tiangolo.com/tutorial/response-model/) · [FastAPI · Handling Errors](https://fastapi.tiangolo.com/tutorial/handling-errors/)

```python
from typing import Annotated, Literal

from fastapi import FastAPI, HTTPException, Path
from fastapi.testclient import TestClient
from pydantic import BaseModel

app = FastAPI()
books = {1: {"id": 1, "title": "图书 A", "internal_note": "仅供运营"}}


class BookOut(BaseModel):
    id: int
    title: str


class MissingBookDetail(BaseModel):
    code: Literal["BOOK_NOT_FOUND"]
    message: str


class MissingBookResponse(BaseModel):
    detail: MissingBookDetail


@app.get(
    "/books/{book_id}",
    response_model=BookOut,
    responses={404: {"model": MissingBookResponse, "description": "图书不存在"}},
)
def read_book(book_id: Annotated[int, Path(ge=1)]):
    book = books.get(book_id)
    if book is None:
        detail = MissingBookDetail(code="BOOK_NOT_FOUND", message="未找到这本书")
        raise HTTPException(status_code=404, detail=detail.model_dump())
    return book


with TestClient(app) as client:
    found = client.get("/books/1")
    assert found.status_code == 200
    assert found.json() == {"id": 1, "title": "图书 A"}

    missing = client.get("/books/2")
    assert missing.status_code == 404
    assert missing.json()["detail"]["code"] == "BOOK_NOT_FOUND"
    assert client.get("/books/0").status_code == 422

    operation = client.get("/openapi.json").json()["paths"]["/books/{book_id}"]["get"]
    schema = operation["responses"]["404"]["content"]["application/json"]["schema"]
    assert schema["$ref"].endswith("/MissingBookResponse")
```

保存成 `responses_demo.py`，按 [专题依赖](./README.md) 安装后用 `python responses_demo.py` 运行。

## 改接口时检查实际返回和 OpenAPI

仅在 `responses` 添加一条声明，FastAPI 会更新文档，处理函数仍须返回对应的状态码和结构。直接返回 `JSONResponse` 或其他 `Response` 时，应用负责正文构造，常规响应模型的自动转换和过滤会被跳过。需要定制错误时，可以把这一层集中到异常处理器里，再用接口测试核对实际响应与文档。 [FastAPI · Additional Responses](https://fastapi.tiangolo.com/advanced/additional-responses/)

联调时将可预期的 404 和请求校验失败分开处理。处理函数返回的数据不符合响应模型属于服务端错误，应从服务端日志定位。这个区分有助于判断是表单发错了数据、资源不存在，还是接口实现跟声明不一致。
