学习工作台的番茄钟会跨页面显示。用户切换标签页、刷新或断掉网络，页面仍要给出有用的时间反馈。还要避免把离线时间直接记入学习统计。这里有两个不同的契约，屏幕显示剩多少，服务端确认记多少。

## 定时器触发刷新，时钟决定显示

后台标签页的定时器可能被节流。如果用一次 `setInterval` 回调减一秒，卡住五秒后页面可能只少一秒。收到服务端快照时，可以用 `performance.now()` 记一个本地观测点。每次绘制用当前时间与观测点的差，计算这段时间走了多少；定时回调只负责安排重绘。[MDN · 非活动标签页的定时器限制](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout#timeouts_in_inactive_tabs) · [MDN · performance.now](https://developer.mozilla.org/en-US/docs/Web/API/Performance/now)

这份简化示例使用毫秒作为内部单位。剩余心跳窗口来自同一服务端快照。收到新快照就换一组基准，显示估算最多走到该窗口结束。

```js
import assert from 'node:assert/strict'

function remainingMs(snapshot, receivedAtMs, nowMs) {
  if (snapshot.state !== 'running') return snapshot.remainingMs

  const elapsedMs = Math.max(0, nowMs - receivedAtMs)
  const estimateMs = Math.min(elapsedMs, snapshot.heartbeatWindowLeftMs)
  return Math.max(0, snapshot.remainingMs - estimateMs)
}

const snapshot = {
  state: 'running',
  remainingMs: 60_000,
  heartbeatWindowLeftMs: 20_000,
}

// 中间漏了多少次回调，下一帧都按实际经过的时间重新算。
assert.equal(remainingMs(snapshot, 1_000, 6_000), 55_000)
assert.equal(remainingMs(snapshot, 1_000, 31_000), 40_000)
assert.equal(remainingMs({ ...snapshot, state: 'interrupted' }, 1_000, 31_000), 60_000)
assert.equal(remainingMs({ ...snapshot, remainingMs: 2_000 }, 1_000, 6_000), 0)
```

把代码保存成 `timer.mjs`，用 Node.js 可验证跳过回调、窗口封顶和归零。设备休眠时单调时钟的推进在平台之间存在差异，回到前台后应重新读服务端状态。不同会话的响应先按会话 ID 区分，同一会话再按版本和服务端快照时间判断新旧。

## 用心跳窗口界定可计时的区间

工作台每 60 秒尝试发一次心跳，服务端最多计到上一条有效心跳后 90 秒。核算时先比较计划结束点。如果在有效窗口内达到计划时长，就按实际达到的时间完成；如果窗口先用尽，就冻结这一段，等待用户显式继续。迟到的心跳不会补上窗口以外的时间。

| 事件 | 状态与界面 |
| --- | --- |
| 刷新或回前台 | 先读取并核算当前会话，再尝试心跳 |
| 心跳窗口到期 | 页面停止继续估算，服务端确认中断后展示继续入口 |
| 倒计时显示为零 | 页面可以提示正在核对，学习记录和打卡以服务端完成为准 |
| 用户修改专注参数 | 等下一轮生效，当前计划和休息长度沿用启动时的参数快照 |

这里给断线多留了一点余量，避免轻微网络抖动直接中断。如果产品希望离线也能独立计时，就要另外定义本地计时记录、同步冲突和设备可信度。

## 用真实跑时和故障注入分开验证

原项目在本地浏览器完整跑了一轮 5 分钟，对照服务器实际记下的 300 秒和仪表盘结果。中断场景则通过服务端时钟偏移跨过窗口，验证了冻结、继续和放弃。两组验证的覆盖面不同，前者是一次真实运行，后者检查时间边界。

实际演练还发现一个量纲错误，休息秒数直接加到了以毫秒计的时间点上，导致界面几乎立即归零。修正后复验了 `01:00 → 00:59`。这一类问题值得直接给变量加单位后缀，再用快照和时间差做断言。有效段如何分摊到日历日期，可以和[统计报表对账](./统计报表怎么对账.md)一并核对。
